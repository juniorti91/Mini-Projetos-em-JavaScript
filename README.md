# Mini-Projetos-em-JavaScript

Este repositório contém uma coleção de mini aplicações desenvolvidas em JavaScript puro, com o objetivo de praticar e aprimorar os conhecimentos adquiridos na linguagem.

## Estrutura do Repositório

A estrutura do repositório é organizada da seguinte forma:

- **CRUD Completo**: Implementação de um sistema completo de CRUD (Criar, Ler, Atualizar, Excluir) utilizando JavaScript.
- **Calculadora IMC**: Aplicação para cálculo do Índice de Massa Corporal (IMC).
- **Calculadora**: Calculadora simples para operações matemáticas básicas.
- **CountDown**: Contador regressivo para eventos ou tarefas.
- **DrumKit**: Simulador de bateria com sons ao pressionar teclas.
- **Lampada**: Controle de lâmpada que alterna entre ligado e desligado.
- **Semaforo**: Simulação de semáforo com controle de cores.
- **ToDoList**: Lista de tarefas com funcionalidades de adicionar, editar e remover itens.

## Tecnologias Utilizadas

- **JavaScript**: Linguagem principal para a lógica de programação.
- **HTML5**: Estruturação do conteúdo e elementos da interface.
- **CSS3**: Estilização e layout das páginas.
